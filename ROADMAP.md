# Project Roadmap

This roadmap tracks the development of the Student Information System.

The project is developed incrementally, with each version building upon the previous one.

---

## Completed

### v0.1.0 — Project Foundation

- Initial C++ project
- Basic project structure
- Student class
- Initial application flow

### v0.2.0 — Student Management

- Student records
- Add students
- View students
- Search students
- Edit students
- Delete students
- Student data persistence

### v0.3.0 — Authentication & Role-Based Access

- Administrator login
- Student login
- Role-based menus
- Role-based access

### v0.4.0 — Student Portal

- Student details
- Student information updates
- Password changes
- Student grade viewing

### v0.5.0 — Student Management Improvements

- Improved student management
- Student profile information
- Student year of study
- Student programme
- Student contact information

### v0.6.0 — Course Management

- Course creation
- Course viewing
- Course searching
- Course editing
- Course deletion
- Course persistence
- Course programme and year information

### v0.7.0 — Lecturer Management

- Lecturer registration
- Lecturer viewing
- Lecturer searching
- Lecturer editing
- Lecturer deletion
- Lecturer authentication
- Lecturer portal
- Lecturer profile management
- Lecturer password management

### v0.8.0 — Lecturer-Course Assignment

- Assign lecturers to courses
- View lecturer courses
- View course lecturer
- Remove lecturer assignments

### v0.9.0 — Student Course Registration

- View available courses
- Programme validation
- Year-of-study validation
- Course registration
- View registered courses
- Drop courses
- Duplicate registration prevention
- Maximum course limit
- Registration persistence

### v1.0.0 — Continuous Assessment & Results Management

- Test 1 mark entry
- Test 2 mark entry
- Assignment/quiz contribution where applicable
- CA calculation
- Final examination entry
- Final mark calculation
- Grade calculation

- Student result viewing
- Result persistence

- Architecture improvements
- Bug fixes
- Regression testing

## Future Development

### v1.1.0 — Academic Management Improvements

Potential areas:

- More detailed student result breakdown
- Improved result management
- Academic reports
- Administrative result oversight
- Result publication controls

### Future Versions

Potential areas:

- Improved data management
- Database integration
- Additional security improvements
- More advanced academic functionality

### Future Web Version

A future version of the project may transform the console-based system into a web-based Student Information System.

The web version will build upon the concepts, workflows and business rules developed in the C++ application.
